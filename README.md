# 📚 Talleres de Python

Este repositorio contiene los ejercicios desarrollados durante el curso de **Python**, en los que se aplican conceptos fundamentales de programación y Programación Orientada a Objetos (POO).

## 📋 Contenido

El repositorio incluye los siguientes ejercicios:

### 1. 📖 Gestión de Libros
Se desarrolló una clase `Libro` que permite:

- Crear libros con título, autor y número de páginas.
- Consultar la información del libro.
- Prestar un libro.
- Devolver un libro.
- Controlar su disponibilidad.

**Conceptos utilizados:**

- Clases
- Objetos
- Métodos
- Constructor (`__init__`)
- Atributos

---

### 2. 💳 Cuenta Bancaria
Se implementó una clase `CuentaBancaria` utilizando el principio de encapsulación.

Funciones principales:

- Consultar el titular.
- Consultar el saldo.
- Depositar dinero.
- Retirar dinero.
- Validar que el saldo nunca sea negativo.

**Conceptos utilizados:**

- Encapsulación
- Atributos privados
- Propiedades (`@property`)
- Setters
- Validación de datos

---

### 3. 💻 Sistema de Préstamos de Equipos
Se desarrolló una aplicación en consola para administrar préstamos de equipos.

Permite:

- Ver los equipos disponibles.
- Registrar préstamos.
- Devolver equipos.
- Consultar el historial de préstamos.
- Agregar nuevos equipos.

**Conceptos utilizados:**

- Diccionarios
- Listas
- Tuplas
- Funciones
- Ciclos (`while` y `for`)
- Condicionales (`if`, `elif`, `else`)
- Menús interactivos

---

## 🛠️ Tecnologías utilizadas

- Python 3

No se utilizaron librerías externas; todos los ejercicios fueron desarrollados únicamente con las herramientas básicas del lenguaje Python.

## ▶️ Cómo ejecutar los ejercicios

1. Clona este repositorio:

```bash
git clone https://github.com/tu-usuario/nombre-del-repositorio.git
```

2. Entra en la carpeta del proyecto:

```bash
cd nombre-del-repositorio
```

3. Ejecuta el archivo que desees:

```bash
python nombre_del_archivo.py
```

Por ejemplo:

```bash
python libro.py
```

o

```bash
python prestamos_equipos.py
```
